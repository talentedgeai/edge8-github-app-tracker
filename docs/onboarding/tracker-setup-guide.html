Edge8 · One-time setup · ~15 minutes

Set up the Edge8 Work Tracker on your computer

This guide assumes zero technical background. You'll copy and paste a few commands, and at the end your computer will automatically connect to Edge8's code repositories — no passwords, no GitHub account needed.

What is this, in one paragraph?

Edge8 tracks engineering work directly from git — the tool developers use to save and share code. You'll install a small helper called the tracker. After that, whenever you download or upload code for an Edge8 project, the tracker quietly logs that activity and grants you access automatically. It does not watch your screen, record keystrokes, or touch your personal files — it only sees git activity on company repositories.

How the whole flow runs — two roles

🔑 Admin once per engineer

  1. Repo under a new owner? Get the App installed on that org/user first — see Step 0
  2. Creates an engineer key (e8k_…) — see Part A
  3. Downloads the latest tracker.tgz installer
  4. Sends both privately to the engineer
→

💻 Engineer once per machine

  1. Installs Node.js + Git — see Part B
  2. Installs the tracker (npm i -g)
  3. Activates it with the key (tracker setup)
  4. Works normally — git access & tracking are automatic

Behind the scenes: on every git clone/pull/push of a tracked repository, the engineer's key mints a fresh 60-minute access token from the tracker server and the activity is logged. No passwords, no personal GitHub account involved.

Part A — Admin: create & send the key Admin

Already received your e8k_… key and tracker.tgz? You're the engineer — skip to Part B.

0

Repo outside the org? Install the App on its owner first

The tracker only covers repositories whose owner (org or user account) has the GitHub App installed. Repos under talentedgeai are already covered. For a repo under any other owner, do this once per owner:

  1. Someone with an account in the target org (or the account owner, for personal repos) opens github.com/apps/edge8-github-app-tracker → Install → picks that org/user → choose All repositories (recommended — future repos auto-track) or select specific repos.
  2. If that person is the org owner/admin: the install completes immediately. Done.
  3. If they are NOT the owner: the button becomes Request — GitHub turns it into an installation request and emails the org owners. An owner approves it via the link in that email, or at Org Settings → Third-party Access → GitHub Apps (owners can adjust the repo list before approving). Nothing is installed until an owner accepts.
💬 The GitHub email is easy to miss — after clicking Request, message the org owner directly so they approve it right away.
⚠️ Personal accounts have no request flow — only the account owner themselves can install the App on a personal account.

After the install is accepted there is nothing else to configure — the server detects it automatically, and existing engineer keys work on the new repos immediately. Now continue with steps 1–3 below.

1

What you need: the admin token

Key creation is guarded by the ADMIN_TOKEN — a live secret (its home is Vercel → project settings → Environment Variables). The current value for this instance — use it wherever the commands below say YOUR_ADMIN_TOKEN:

ADMIN_TOKEN = DhzMI2qGCa
⚠️ This is a live secret — handle with care. Anyone holding it can mint keys that reach every tracked repo in every covered org. Admins only: never share it with engineers, never paste it into group chats or client code. If it leaks or an admin leaves, rotate it immediately (set a new value in Vercel env → redeploy → update this guide and the README).
2

Create the engineer's key

Replace YOUR_ADMIN_TOKEN and the engineer's email, then run in a terminal:

Mac / Linux:

curl -X POST https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys \
  -H "x-admin-token: YOUR_ADMIN_TOKEN" -H "content-type: application/json" \
  -d '{"email":"engineer@edge8.ai"}'

Windows (PowerShell):

Invoke-RestMethod -Method Post -Uri "https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys" `
  -Headers @{ "x-admin-token" = "YOUR_ADMIN_TOKEN" } `
  -ContentType "application/json" -Body '{"email":"engineer@edge8.ai"}'

✔ The response contains a "key" field: e8k_xxxxxxxx_yyyy…

⚠️ The full key is shown exactly once — only its hash is stored on the server. Copy it now; if it's lost, revoke it and create a new one.
3

Send the engineer their starter pack — privately

Via a private channel (DM, password manager share — not a group chat), send:

  • The key from step 2
  • The tracker.tgz installer — download the latest from the Releases page, or with the GitHub CLI:
gh release download --repo talentedgeai/edge8-github-app-tracker --pattern "*.tgz" -O tracker.tgz
  • This guide, and the name of the repo they'll work on (for their final check)

Managing keys later (list / revoke)

List all keys (no secrets shown):

# Mac/Linux
curl https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys -H "x-admin-token: YOUR_ADMIN_TOKEN"

# Windows PowerShell
Invoke-RestMethod -Uri "https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys" -Headers @{ "x-admin-token" = "YOUR_ADMIN_TOKEN" }

Revoke a key (e.g. an engineer leaves — takes effect immediately):

# Mac/Linux
curl -X DELETE https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys \
  -H "x-admin-token: YOUR_ADMIN_TOKEN" -H "content-type: application/json" \
  -d '{"key_id":"e8k_xxxxxxxx"}'

# Windows PowerShell
Invoke-RestMethod -Method Delete -Uri "https://edge8-github-app-tracker-kappa.vercel.app/api/admin/keys" `
  -Headers @{ "x-admin-token" = "YOUR_ADMIN_TOKEN" } `
  -ContentType "application/json" -Body '{"key_id":"e8k_xxxxxxxx"}'

The key_id is the short prefix (first two segments) of the engineer's key — visible in the list command above.

Part B — Engineer: set up your machine Engineer

Before you start, you need these two things from your admin

  • Your personal engineer key — a code that starts with e8k_ (e.g. e8k_1a2b3c4d_5e6f…). Ask your admin; they'll send it to you privately.
  • The tracker installer file — a file named tracker.tgz. Ask your admin to send it, and save it into your Downloads folder.
💬 Not sure who to ask? Message: "Hi! I'm setting up the Edge8 tracker. Could you send me my engineer key and the tracker.tgz installer? My work email is ____."  (Admins: Part A above shows how to create these.)

B1 — Open a terminal

A terminal is a window where you type commands instead of clicking. You'll paste commands into it.

Your computerHow to open it
WindowsPress the Start button, type powershell, press Enter.
MacPress Cmd + Space, type terminal, press Enter.

To run a command: copy it, paste it into the terminal, press Enter, and wait for it to finish (a new blinking line appears).

B2 — Install the two free tools the tracker needs

1

Install Node.js (the engine the tracker runs on)

Go to nodejs.org, download the LTS version, and run the installer. Click Next through every screen — the defaults are fine.

Then close and reopen your terminal, and check it worked:

node -v

✔ You should see a version number like v20.11.0 (anything 18 or higher is fine).

2

Install Git (the tool that talks to code repositories)

Windows: download from git-scm.com and run the installer — defaults are fine.
Mac: just run the check below; if Git is missing, your Mac will offer to install it — click Install.

Check (reopen the terminal first if you just installed):

git --version

✔ You should see something like git version 2.45.0 (2.34 or higher is fine).

B3 — Install and activate the tracker

3

Install the tracker

Make sure tracker.tgz (from your admin) is in your Downloads folder. In the terminal, run these two commands one at a time:

cd Downloads
npm i -g ./tracker.tgz

✔ After ~10 seconds it prints a line like added 1 package. Warnings in yellow are OK.

⚠️ Mac only: if you see an error containing EACCES or permission denied, run sudo npm i -g ./tracker.tgz instead and type your Mac login password when asked (it won't show as you type — that's normal).
4

Activate it with your key

Copy the command below into a notes app first, replace PASTE_YOUR_KEY_HERE with the e8k_… key your admin sent you, then paste the whole line into the terminal:

tracker setup --key PASTE_YOUR_KEY_HERE --server https://edge8-github-app-tracker-kappa.vercel.app

✔ It should print: tracker: setup complete ✔

That's it — the setup checks your key with the server, so if it says complete ✔, everything works.

5

Prove it works (optional but satisfying)

Ask your admin which repository you'll be working on, then run (replace REPO-NAME):

git clone https://github.com/talentedgeai/REPO-NAME.git

✔ The project downloads into a folder — without asking you for any username or password. That silence is the tracker doing its job.

⚠️ If a login window pops up asking for a GitHub password, something's off — see Troubleshooting below.

😵 Something went wrong?

What you seeWhat it means & the fix
'node' is not recognized or command not found: node Node.js isn't installed yet, or the terminal was opened before you installed it. Install from nodejs.org, then close and reopen the terminal.
'tracker' is not recognized Close and reopen the terminal — it needs a restart to notice newly installed commands. If it persists, redo Step 3.
ENOENT … tracker.tgz The terminal can't find the installer file. Make sure tracker.tgz is in your Downloads folder and you ran cd Downloads first.
key rejected by the server (401) The key was mistyped or has been revoked. Re-copy the entire key from your admin's message (it's long!) and run Step 4 again. Still failing? Ask your admin for a fresh key.
Git asks for a username/password when cloning Either setup didn't finish (redo Step 4) or that repository isn't covered yet — its owner may not have the App installed (see Part A, Step 0). Tell your admin which repo you tried.
Admin {"error":"unauthorized"} The x-admin-token header is wrong or missing — re-copy ADMIN_TOKEN from the Vercel environment variables.
Admin {"error":"email required"} The request body is malformed or the email is missing/invalid — check the JSON in -d / -Body.
Anything else Take a screenshot of the whole terminal window and send it to your admin — that's genuinely the fastest fix.

❓ Quick answers

Does it spy on me? No. It only logs git activity (downloads/uploads of code) on Edge8-tracked repositories. No screen recording, no keystrokes, no personal files, and your personal projects are untouched.

Do I need a GitHub account? No. Your e8k_ key grants access to Edge8 repositories all by itself.

Will it slow anything down? No — access tokens are cached for 60 minutes and refreshed automatically in the background.

New laptop? Just repeat this guide on the new machine with the same key (keep your key saved somewhere safe, like a password manager).

How do I remove it? Run tracker uninstall in a terminal. Done.

An engineer left the team? Admin revoke their key (see Managing keys in Part A) — their access stops within the hour, as soon as the last 60-minute token expires.
